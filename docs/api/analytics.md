# 盈亏分析与盈亏日历接口

盈亏分析接口服务 PC 端“盈亏分析页”和“盈亏日历页”，也可给移动端复盘视图使用。所有接口只读，需要登录。

## 盈亏分析

```http
GET /api/analytics/profit?startDate=2026-06-01&endDate=2026-06-30
```

参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `startDate` | 否 | 开始日期，格式 `yyyy-MM-dd`。默认最近 30 天。 |
| `endDate` | 否 | 结束日期，格式 `yyyy-MM-dd`。默认今天。 |

返回内容：

- 当日收益
- 本周收益
- 本月收益
- 今年收益
- 全部收益
- 选定区间收益和收益率
- 周期统计列表
- 收益走势
- 盈利 TOP5
- 亏损 TOP5
- 免责声明

当前版本的收益走势来自 `holding_snapshot` 每日快照；如果尚未生成快照，走势为空，当前总收益仍来自账户汇总。

指数对比、盈利用户占比、跑赢指数情况已在响应中预留状态说明，后续接入市场指数数据和多用户统计后启用。

## 盈亏日历

```http
GET /api/analytics/profit-calendar?month=2026-06
```

参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `month` | 否 | 月份，格式 `yyyy-MM`。默认当前月。 |

返回内容：

- 月累计收益
- 月收益率
- 每日收益金额
- 每日收益率
- 每日累计收益
- 热力等级：`STRONG_PROFIT`、`PROFIT`、`FLAT`、`LOSS`、`STRONG_LOSS`
- 盈利 TOP5
- 亏损 TOP5
- 免责声明

## 安全边界

- 接口只读取当前登录用户数据。
- 不触发真实交易。
- 不生成买卖指令。
- 不承诺收益。
- 所有展示建议仍需显示“仅供参考，不构成投资建议，不承诺收益”。
