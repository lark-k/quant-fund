# 收益分析与收益日历

收益接口服务驾驶舱、收益分析和收益日历页面，只读取当前登录用户数据，不触发策略或交易。

Base path：`/api/analytics`

## 区间收益分析

```http
GET /api/analytics/profit?startDate=2026-06-01&endDate=2026-06-30&indexCode=000300
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `startDate` | 否 | `yyyy-MM-dd`，默认最近 30 天 |
| `endDate` | 否 | `yyyy-MM-dd`，默认今天 |
| `indexCode` | 否 | 对比指数代码；未传时由服务选择默认指数 |

返回内容包括：

- 当日、本周、本月、今年和全部收益；
- 区间收益金额、收益率和周期统计；
- 基于持仓快照的组合收益走势；
- 市场指数走势、指数收益和组合超额收益；
- 盈利 TOP5 与亏损 TOP5；
- 数据状态和免责声明。

历史组合曲线主要来自 `holding_snapshot`。市场基准来自 `market_index_daily`；当对应日期或指数数据不足时，接口返回可用组合数据和明确的数据状态，不伪造指数表现。

## 盘中收益走势

```http
GET /api/analytics/profit-intraday?indexCode=000300
```

返回当天盘中快照序列，主要字段包括时间、组合收益率、指数收益率和当日收益金额。数据来自 `portfolio_intraday_snapshot` 和市场指数盘中/日内数据，用于收益分析页面的盘中曲线。

没有盘中快照时返回空列表，这是未积累数据的正常状态。

## 收益日历

```http
GET /api/analytics/profit-calendar?month=2026-06
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `month` | 否 | `yyyy-MM`，默认当前月；格式错误返回 400 |

返回内容：

- 月累计收益和月收益率；
- 每日收益金额、收益率和累计收益；
- `STRONG_PROFIT`、`PROFIT`、`FLAT`、`LOSS`、`STRONG_LOSS` 热力等级；
- 当月盈利 TOP5 与亏损 TOP5；
- 免责声明。

## 数据时点

- 盘中数据来自估值刷新后的账户快照，只作实时参考；
- 日终表现以正式净值同步和持仓快照为准；
- 刚初始化或尚未运行快照任务的环境，历史走势和日历可能为空；
- 可通过后端快照回补逻辑补齐配置范围内的历史交易日。

## 安全边界

- 只查询当前登录用户的账户、持仓和快照；
- 不生成买卖指令，不触发真实或模拟交易；
- 指数和基金公开数据可能延迟或缺失；
- 所有结果仅用于复盘，不承诺收益。
