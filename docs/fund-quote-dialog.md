# 首页基金行情弹窗

## 图表视觉升级

- 主净值曲线使用更清晰的渐变描边、轻微阴影、渐隐面积和最新值端点；保留原始折线转折，不改变价格数据或收益计算。
- 画布以至少2倍像素密度渲染，均线收细、降低饱和度；最新净值贴右侧显示，成本标签移至左侧，买卖点使用小三角标记。
- 图例分布到各自图层并提供末值读数；只有底部显示时间轴。副图间距、网格和缩放条统一简化。
- 默认仅保留一行数据状态；数据口径、异常详情和买卖记录均可按需展开。
- 已验证所有副图同时开启、周K、缩放、交易标记点击、390px布局和关闭弹窗；浏览器检查未发现新错误。

入口：点击首页「自选/持仓监控」中的基金名称。使用独立、懒加载的弹窗，不添加菜单或路由，不修改原基金详情页、持仓计算、交易处理、数据库结构和后端服务。

## 查看期间保持稳定

首页轮询更新同一基金的持仓对象不会触发行情重载。弹窗保留打开时的持仓快照，图表、成本线、缩放、图例选择和滚动位置不受后台更新影响。重新打开、切换基金/参考指数或点击刷新时重新读取；首页原有自动刷新继续运行。

回归脚本 `quant-fund-web/scripts/fund-quote-refresh-check.js` 可通过 Playwright CLI `run-code --filename=...` 在已登录的 mock 开发首页执行。已验证连续5次持仓对象替换及一次原地修改不增加净值请求、不重置图表；主动刷新、参考指数切换和基金切换仍正常加载。

## 功能对照

1. 首页名称按钮打开弹窗，支持键盘操作。
2. 基金名称、代码、正式净值、日涨跌幅、净值日期和读取时间。
3. 每日单位净值曲线。
4. 周/月聚合蜡烛图，使用首个、末个、最低、最高日净值。
5. 近1月、3月、6月、1年和成立以来。
6. 十字光标、数据提示、滚轮缩放、拖动和多副图联动。
7. MA5/10/20/60，按当前图表周期计算，独立开关。
8. 当前持仓金额、份额、收益、收益率、当日收益和成本。
9. 当前单位成本参考线，可关闭；纵轴包含成本。
10. 当前账户/持仓已完成交易标记，点击显示明细；同时提供可滚动的记录表。
11. 日涨跌幅副图，周/月采用每日收益复合。
12. 回撤副图，以已加载历史最高净值计算；周/月显示期末回撤。
13. MACD(12,26,9)、RSI(14)，样本不足不画虚构值。
14. 参考指数对比副图，采用共同可用起点归零。复用既有接口支持的沪深300、创业板指、上证指数和深证成指。资料中的跟踪指数精确匹配支持列表时可一键对比；未明确匹配的ETF或其他指数不擅自替代。
15. 盘中估值独立显示日期/时间和延迟状态，不并入正式净值曲线。
16. 单位净值/前复权切换。前复权以最新单位净值为锚，依据数据源日收益率反推；交易点按对应日因子换算。
17. 初次加载近两年历史用于指标预热；成立以来按年度分段补齐。支持刷新、失败重试、取消请求、过期响应隔离和数据缺失提示。
18. 深色布局、大尺寸弹窗、全屏和窄屏适配；关闭返回原首页，保留排序与页面状态；弹窗内可切换持仓。

## 数据口径与限制

- 不构造场外基金的盘中OHLC、分钟K线或成交量。
- 前复权依赖上游日收益率正确计入分红和折算。累计净值不当作复权净值。缺失收益率导致无法连续反推时留空。
- 成本线表示当前单位成本，不表示历史盈亏平衡线。
- 现有交易接口只有记录日期，没有独立的净值确认日期；按记录日期定位，未匹配到当日净值或交易净值时仅列明细，不移动标记。只显示COMPLETED记录，并隔离账户与持仓。
- 指数为价格变动；单位净值变动不含分红再投资，前复权变动采用数据源收益率口径。指数休市日可能由已有后端沿用前值。
- 分段请求的指数基准通过重叠日期换算；无重叠时保留未知，避免拼接虚假趋势。
- 历史源可能返回本地缓存或部分数据，展示实际覆盖区间。超过14个自然日的净值间隔给出提示。成立以来不保证数据源完整。
- 组件仅读取既有API；后端历史净值接口原有的数据同步/缓存行为保持不变。

## 今日交易推荐（NAV-TA v1）

- 位于看图指南左侧，独立弹窗。每次打开或手动重新分析读取该基金近两年正式净值、基本资料和市场状态，不使用盘中估值，不改变主图缩放或原策略信号。
- 纯函数 `analyzeFundTechnicals` 固定取最近 120 点前复权净值，复用 MA、MACD(12,26,9)、RSI14 算法，联合已结束的相邻两周净值 K 线。原始单位净值分红跳变不直接参与判断。
- MA 排列/斜率、MACD 零轴/两线位置、周 K 方向须全部同向；买入还须满足 RSI 45–70 和相对 MA20 正乖离不超过 5%。未同时满足则持有或观望。规则完整展示在弹窗中，不输出虚构胜率或金额。这些组合阈值是未回测的启发式规则。
- 数据少于 120 点、收益率缺失、无效/未来数据、历史长间隔、净值过旧、市场状态不可用/非交易日、基金类型不支持时不出买卖结论。日历与新鲜度校验偏保守，长假、QDII 或短周可能暂停建议。
- 展示数据日期、样本数、来源、北京时间和各项数值/解释。15 分钟或跨日期后标记结果过期，需手动重算，不自动重载图表。场外基金实际成交日、费用与申赎限制需按产品规则核对。
- 验证：77 项单元测试通过；`scripts/fund-technical-advice-check.js` 在 mock 开发环境检查按钮位置、读取新数据、数据不足/请求失败、周期独立性、结果过期、基金切换、关闭保留缩放及窄屏布局。浏览器合成数据不会用于生产建议。
- 类型兼容修复：支持后端 `ACTIVE_EQUITY / MIXED / INDEX / INDEX_ENHANCED / ETF / ETF_LINK / QDII` 编码及既有中文类型；债券、货币、固收、FOF、REIT 仍不适用。缺失和未识别类型分别显示原因及实际编码；无法分析不再显示为交易判断。新增生产编码和排除类型回归用例，浏览器夹具改用生产 `MIXED` 编码；不调整指标或数据门槛。
