# 首访花开序章

`FirstVisitIntro.vue` 仅包裹现有 `RouterView`，不替换、不延迟挂载页面，也不改变路由、登录态、业务请求或后端。

- 正常访问：同一标签页会话首次显示；完成或跳过后记录 `sessionStorage`。
- 审核重播：打开 `http://127.0.0.1:5173/?intro=replay`，或在现有页面 URL 加上 `intro=replay` 并刷新。查询参数仅控制展示，不影响鉴权。
- 鼠标进入固定椭圆区域后盛放，离开 150ms 后收拢；中途反向保留当前位置和速度。
- 触屏轻触花朵切换开合；进入按钮独立。键盘支持 Tab、Enter、Escape。
- 点击进入后完成盛放；在开合进度 86% 时提前启动镜头推进，再衔接真实穿花心视频，最后用 900ms 暗场淡出显示原页面。画幅推进仅使用 transform，避免逐帧改变布局尺寸。
- 用户选择减少动态效果时使用静态花苞与 180ms 淡出；素材失败、加载未完成或播放受限时仍可直接进入。
- 原页面在开场期间为 inert，完成后恢复焦点与滚动；离开组件会取消请求、动画和解码资源。

## 持续氛围动画

GSAP 模块只在需要展示序章且未启用减少动态效果时按需加载：

- 7.6 秒往返的浮动与呼吸缩放：桌面最多上浮 18px、旋转 0.65°、放大 4.8%；窄屏使用 65% 幅度。
- 静候的花苞每 6.6 秒轻微舒展、收拢，复用开合视频末段约 18 张帧；相邻帧透明度混合，避免低速切帧产生阶梯感。悬停从当前真实形态继续开合。
- 桌面鼠标视差：横向最多 6px、纵向 3.5px，用 `quickTo` 平滑追随。热区按钮独立于视觉变换，避免运动引起开合反复触发。
- 在现有照片中采样最多 44 颗星（窄屏 28 颗），排除花瓣和花茎区域，交替压暗和提亮原有星光。采样星光同时复用为 84 个远近流动星点（窄屏 42 个），用柔和排除区避开花朵，未新增图片或粒子贴图。
- 星光遮罩仅 640×360，绘制上限 24fps；主体浮动仅更新 transform。花苞星点在初始化时采样，闭合端点复用，不再同步读取画布及重建贴图。开合及完全盛放时淡出花苞星光遮罩，独立星空继续运动。
- 进入时浮动及视差在原位置平稳归中，星光淡出；页面隐藏暂停 GSAP 循环及绘制，恢复时续播；退出、卸载和减少动态偏好会释放动画。

## 素材

原始文件保持在 `qa-artifacts/intro-art-direction/source`：`花朵开合母版.mp4` 与 `穿过花心的进入转场.mp4`。

运行 `python quant-fund-web/scripts/prepare-intro-media.py`（仓库根目录，需安装 FFmpeg）可重现网页素材。当前版本为 `public/intro/flower-v1`：

- 开合：源视频第 36–204 帧，169 张连续 WebP；桌面 1280×720，手机 768×432。交互开合和静置呼吸共用相邻帧透明度混合，没有生成新素材或几何形变。端点减速后才接入呼吸，避免速度突然归零。
- 桌面帧集合约 7.00 MiB，手机约 3.14 MiB，仅下载所需版本；解码缓存最多 22 张位图。
- 进入：H.264、1280×720、48fps、约 5.04 秒、3.40 MiB，无音轨。原素材以 2 倍时间速度播放，无生成中间帧。
- 视频在开合资源就绪后预加载，点击进入时不再重新 load 或 seek。两段原片的花瓣姿态不完全一致，因此开合末段（进度 78% 起）先在同一画布中混合到视频实际解码首帧，再开始播放；已悬停盛放时也保留至少 650ms 的形态交接。首帧未解码时不会直接切入全权重画面。
- 进入视频也绘制到原开合画布，不显示独立 video 图层、不切换 poster，也不在交接瞬间释放位图。支持 requestVideoFrameCallback 时按视频帧更新，不支持时用 requestAnimationFrame 降级；隐藏、退出与卸载均取消对应回调。
- 边缘使用透明遮罩衔接纯黑背景；进入镜头中画幅随视频展开至全屏。
- `/intro/` 路径使用版本化静态缓存。未来替换素材时须升级目录版本，避免长期缓存命中旧文件。

## 校验与更新

`npm run test -- --run` 覆盖中途反向、连续快速反转、30/60/120Hz 下的端点低速到达、标签页恢复的时间跳变、会话记忆与存储不可用。

仅更新前端容器：

```powershell
docker compose build quant-fund-web
docker compose up -d --no-deps quant-fund-web
```

视觉与交互验收见前端项目根目录的 `design-qa.md`。
